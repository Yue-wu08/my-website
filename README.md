## Project Overview

This is a personal digital portfolio website built from scratch using HTML, CSS, and JavaScript. It showcases my skills, projects, and background as a computer science student. The website is fully responsive and works on desktop, tablet, and mobile devices.

## Technologies Used

- **HTML5** - Semantic markup structure
- **CSS3** - Styling, layout, animations, responsive design
- **JavaScript** - Interactive features and dynamic behavior
- **Markdown** - Documentation (this README)
- **Git & GitHub** - Version control and project hosting
- **Visual Studio Code** - Code editor

## Project Structure

```
portfolio-site/
├── index.html      # Main HTML file
├── style.css       # Stylesheet
├── script.js       # JavaScript functionality
├── README.md       # Project documentation
└── assets/         # Images and other assets (if needed)
```

## Features

### 1. Responsive Navigation Bar
- Fixed top navigation with smooth scrolling
- Mobile hamburger menu for small screens
- Active link highlighting based on scroll position

### 2. Hero Section
- Introduction with name and title
- Call-to-action buttons
- Animated avatar circle

### 3. About Section
- Personal background and introduction
- Profile image placeholder

### 4. Skills Section
- Animated progress bars for technical skills
- Tool tags for additional tools and technologies
- Categories: Frontend, Programming, Tools

### 5. Projects Section
- Filterable project cards (All / Web / Python / Other)
- Hover effects on cards
- Project descriptions and tech stack

### 6. Contact Form
- Form with validation (name, email, message)
- Email format checking
- Success/error status messages

### 7. Additional Features
- Smooth scroll animations
- Scroll-triggered fade-in effects
- Hover animations on interactive elements
- Fully responsive layout (mobile, tablet, desktop)

## How to Run

1. Clone this repository to your local machine
2. Open `index.html` in any modern web browser
3. No build step or server required

## Design Decisions

- **Color Scheme:** Dark theme with sky blue accent - chosen for a modern, professional look that is easy on the eyes
- **Typography:** Inter font family - clean, readable, and modern
- **Layout:** Grid-based layout with responsive breakpoints at 768px and 480px
- **Animations:** Subtle transitions and hover effects to enhance user experience without being distracting
- **Accessibility:** Semantic HTML structure and sufficient color contrast
